Trust this computer

Glass on this computer uses its own certificate authority for HTTPS. Install it once on this device, then Glass opens securely. That's needed for the video and the input, which browsers allow only on secure pages.

Install it

Pick this device's system. Restart the browser afterwards, as many only read certificates when they start.

Windows (Edge, Chrome)
  1. Open the downloaded glass-ca.crt and choose Install Certificate…
  2. Choose Current User, then Place all certificates in the following store → Trusted Root Certification Authorities, and finish.
  3. Or from a terminal:
certutil -user -addstore Root glass-ca.crt

Firefox keeps its own list: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import.

macOS (Safari, Chrome, Edge)
  1. Open the downloaded glass-ca.mobileconfig, then System Settings → Privacy & Security → Profiles (or Profile Downloaded) → Install.
  2. Or open glass-ca.crt in Keychain Access, double-click it, open Trust and set it to Always Trust.
  3. Or from a terminal:
sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain glass-ca.crt
Linux (Chrome, Edge, Chromium, Firefox)
  1. Chrome, Edge and Chromium use your NSS database (package libnss3-tools):
certutil -d sql:$HOME/.pki/nssdb -A -t "C,," -n "Glass CA" -i glass-ca.crt
  1. Or in the browser: Settings → Privacy and security → Security → Manage certificates → Authorities → Import, and tick Trust this certificate for identifying websites.
  2. For the whole system (curl, other apps):
sudo cp glass-ca.crt /usr/local/share/ca-certificates/glass-ca.crt && sudo update-ca-certificates

Firefox: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import.

Android
  1. Download the certificate.
  2. Settings → Security (or Security & privacy) → More security settings → Encryption & credentials → Install a certificate → CA certificate → choose glass-ca.crt.
  3. Chrome trusts it for websites straight away.
iPhone, iPad
  1. In Safari, tap Profile for iPhone, iPad, Mac and allow the download.
  2. Settings → Profile Downloaded → Install.
  3. Settings → General → About → Certificate Trust Settings → turn on full trust for this certificate. Until then iOS installs it but doesn't trust it for websites.

Then

Once it's installed, check that this browser trusts it and open Glass over HTTPS.
